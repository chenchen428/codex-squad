Codex 小队把可独立验收的问题交给固定的 Qoder / DeepSeek-Flash 实现成员。主 Codex 保留方案、设计、关键决策与独立验收；结果回到原会话，补充要求沿原任务继续。 Codex Squad hands work that can be independently reviewed to one fixed Qoder / DeepSeek-Flash implementer. Codex keeps design, key decisions, and independent acceptance; results return to the original session, and follow-ups continue the same task.

01 / ROLE

判断留在主会话，执行真正交出去。Judgment stays in the main session. Execution is actually delegated.

每一方负责什么、什么算完成，都写在同一条可检查的协作线里。What each side owns, and what counts as done, live on one inspectable line of work.

保留判断KEEPS JUDGMENT

主 CodexMain Codex

  • 把需求转成可观察完成条件、允许写入范围和验收证据。Turns a request into observable outcomes, allowed write paths, and acceptance evidence.
  • 负责设计、架构取舍和关键决策，必要时直接调查关键路径。Owns design, architecture trade-offs, and key decisions, investigating critical paths when needed.
  • 核对真实差异与实际结果；摘要不能代替源码和证据。Checks actual diffs and results; a summary never substitutes for source and evidence.
  • 完成独立验证后才登记验收，并沿原任务处理返工。Records acceptance only after independent verification, and handles rework on the same task.

承担执行OWNS EXECUTION

Qoder / DeepSeek-FlashQoder / DeepSeek-Flash

  • 唯一实现成员：调查、复现、修改、自检并交付可核验的结果。The single implementer: investigates, reproduces, changes, self-checks, and delivers verifiable results.
  • 在原生任务会话中工作，保留尝试记录、上下文和已报用量。Works in a native task session, preserving attempts, context, and reported usage.
  • 失败时区分产品、测试和环境原因，不把未验证写成通过。Distinguishes product, test, and environment failures; never turns unverified work into a pass.
  • 不创建 Codex 子会话，不递归组队，也不扩大写入授权。Creates no Codex sub-sessions, no nested teams, and no expanded write authorization.
02 / LOOP

一条连续的任务线。One continuous task line.

从范围到证据，再到下一次补充，状态和上下文都不需要重新拼接。From scope to evidence to the next follow-up, neither state nor context has to be rebuilt.

  1. 01

    范围明确Define scope

    先写清目标、写入范围和验收证据。范围重叠时等待，不互相覆盖。State the goal, write scope, and acceptance evidence first. Overlapping scopes wait instead of overwriting each other.

  2. 02

    执行自检Execute and check

    实现成员在原生会话中调查、修改并运行聚焦检查，报告实际结果。The implementer investigates, changes, and runs focused checks in its native session, reporting actual results.

  3. 03

    主 Codex 核验Codex verifies

    主 Codex 查看差异、执行自己的验证，再带证据登记验收。Codex inspects the diff, performs its own verification, then records acceptance with evidence.

  4. 04

    原任务续接Continue the task

    补充、返工和补证继续原任务；收尾时可按需保存恢复总结。Follow-ups, rework, and missing evidence continue the same task; a recovery summary can be saved at closeout.

05 / LIMITS

真实限制，先说清楚。The real limits, stated plainly.

这些边界属于当前公开源码版本，不随介绍页的宣传口径变化。These boundaries belong to the current public source version; they do not change with presentation.

只在本机运行Local only

任务、分析、评审和总结页面由绑定 127.0.0.1 的本机进程提供。URL 含会话凭据，不应外发。Task, analysis, review, and summary views come from a local process bound to 127.0.0.1. URLs contain session credentials and should not be shared.

一名固定实现成员One fixed implementer
