# 可选录制与步骤定位

本节只适用于已有真实 rrweb 录制、希望附加回放的情况。默认流程表达不需要录制，直接按数据合同填写 pageView 即可。不要把页面表达或截图改称真实录制。

## 使用已有采集能力

可消费 ChromePilot 的离线导出会话，或测试工具已经生成的 rrweb JSON。不要求安装 ChromePilot 才能生成验收包。

当前环境若具有 ChromePilot `rec` 能力，先通过其当前 `--help` 确认版本与命令。与该能力配套的命令示例如下；旧版本未必支持，不要据此自动升级、重载扩展或重启共享 bridge：

```sh
chromepilot rec on --tab <目标标签ID>
# 按已授权的测试步骤操作目标页面
chromepilot rec off --tab <目标标签ID>
chromepilot rec digest <会话ID>
```

标签必须来自本次已确认的页面作用域，不猜活动标签。只在生成回放时才读取完整事件（相应版本支持 `rec show <会话ID> --raw`）；日常分析先看摘要。也可通过 Recording Studio 导出离线包，安全解压后取 `sessions/*.rec.js`，不需要执行它们。

若当前工具没有录制能力，使用默认页面表达。是否通过取决于真实执行与核对结果，不能仅因没有录制就改成阻断，也不能因有页面表达就改成通过。

## 组织录制与步骤

- 一个完整业务流程可以复用同一份录制，由不同用例、步骤引用不同时间点；不要为每条断言复制长录像。
- `recordingId` 必须指向该次操作的录制；用例里的环境、版本、测试数据与录制一致。
- 本模块的 `atMs` 相对**首个 rrweb 事件的 timestamp**。ChromePilot 摘要或网络时间轴可能相对会话创建时间，两者不能直接混用。先对齐绝对时间戳，再减去首事件时间戳，最后实际回放核对。
- 时间点应指向该操作开始附近；操作后的断言另写实际结果与证据。可用 `endMs` 标记片段边界，不修改原始事件时间戳来伪造执行速度或顺序。
- 回放里没有对应页面或操作时，检查原始采集是否开始过晚、跳页是否进入其他标签、录制是否退化。不要通过新图或手写事件补造当时的执行画面。

## 离线与隐私

原始录制可能含 DOM 文本、输入、页面 URL、网络参数和日志。整理数据前脱敏，不把账户凭证或不相干用户的录制打入验收包。尽量在采集侧内联样式与必要图片；离线包不会通过网络重取外部资源。

验收生成器只展示材料，不代替业务权限与测试授权，也不证明录制中的操作产生了预期的数据库、消息或资金结果。相应核对仍需原始证据。
