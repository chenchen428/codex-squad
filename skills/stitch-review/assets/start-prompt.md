# Stitch 设计审阅启动提示词

请使用 `$stitch-review`，把本轮界面反馈做成可直接审阅的改稿与本地交互页。中文沟通。

本轮产品/页面：〔填写〕。当前稿、真实运行入口与参考：〔填写〕。允许修改的范围：〔填写〕。当前已明确采用的决定：〔填写，没有则待选〕。

先核准确当前稿与状态，保留问题原话、实测证据、设备尺寸、喜欢/不喜欢及旧备注。通过 Stitch MCP 从确切 screen 改稿；同类页面一组，提供当前和多个有实质取舍的候选（默认两个，按需要增加），明确小修可一个。推荐不自动选择，相关状态与图像身份必须对应；区分原始 Stitch、来源修复浏览器稿和真实产品截图。

先做出具体可点的画布选稿页：不需左侧菜单或流程导航，当前与多个候选同时排列，轻量切组和状态，备注与确认悬浮。拖动/普通滚轮平移整块画布，Ctrl/Command 加滚轮按光标缩放，支持双指缩放、适应全部、同宽、单稿定位和总览；查看/定位不自动选择。桌面横稿、移动端和长页按原始比例呈现，不套手机/浏览器外壳、圆角卡片或粗选中边；完整图默认适配，长稿不裁断，可打开独立大图缩放、拖动、复位、全屏及交互稿。每组可选择或保留当前，多行备注未选也能写，跨组/版本/刷新保留，清单可复制含备注。审阅组用显示状态与进度的自定义选择器；确认后引导下一组，跳过已确认项，待改不能算完成。全部确认后进入结果页，让用户检查并点击“复制结果给 Agent”，再自行粘贴发送；不自动发送或让 Agent 查询本机决定。复制结果包含准确方案版本/图稿身份和原话备注，未确认项不代表采用。确认组锁定；保留当前但仍要求重来时继续改稿待复选，不能标完成。保留原话和决定历史；QA 用独立存储。

Agent 只以用户主动粘贴的结果或对话中直接明确的决定判断采用，不自行读取页面、浏览器存储或剪贴板推断授权。只有明确采用并已授权的项才进入产品实现，已有授权不重复问。要求还原时，必须先导出准确 Stitch HTML 与素材，基于导出结构、样式和资源还原，不得只参考配色再重写另一套布局。实施后用同宽同状态实测图对照，检查 Header/返回/系统胶囊、安全区、完整图、短高窄屏、滚动和跨页一致性。真实浏览器操作验证，不能用测试通过代替视觉判断或宣称像素完全一致。

先交付可打开预览与 Stitch 工程，说明设计、已实现交互、产品实现和未测部分。Stitch 不可用如实说明；不把手写页面冒充导出。不擅自公开私有素材、同步云文档或扩大业务修改范围。
