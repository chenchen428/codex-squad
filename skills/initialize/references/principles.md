# 用于融合的五项原则

保留项目原有措辞，按实际差异融合：

1. **简洁优先**：只实现当前已确认需求的最小完整方案，不添加推测功能、配置或抽象。
2. **精准修改**：只改必要范围，遵循既有风格，保留其他会话 WIP；不顺手重构或清理无关代码。
3. **目标驱动**：先明确可观察完成条件，再验证实际行为；区分实现、验证、验收、提交和发布，未通过就继续修正。
4. **小队协作**：简单查询和少量现成命令由主 Codex 直接完成；需要持续调查、修改与验证且可独立验收的问题，优先交给固定 Qoder 成员完整执行。主 Codex 负责方向、方案取舍、设计与独立验收，复核根因，证据不足时补查或接手关键部分。效率优先，不为 Token 占比强行委派；派工与续接遵守已安装的 `codex-squad:codex-squad` 技能。
5. **会话总结**：总结供 Agent 恢复上下文，保持简洁，不打扰用户；具体时机与操作遵守 `codex-squad:session-summary` 技能。

AGENTS.md 只融合上述原则，不复制并发上限、CLI 参数、写入锁、通知句式、链接格式或总结流程；操作细则由插件技能维护。
